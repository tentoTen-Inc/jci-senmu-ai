一般社団法人猪苗代青年会議所（以下「当会」といいます）は、当会が会員向けに提供する業務支援サービス「猪苗代専務AI」（LINE 公式アカウント、管理画面およびこれらに付随する機能を含みます。以下「本サービス」といいます）における利用者の情報の取扱いについて、以下のとおりプライバシーポリシー（以下「本ポリシー」といいます）を定めます。

1. 取得する情報

本サービスでは、次の情報を取得します。

  • 会員情報：氏名、ふりがな、生年月日、所属委員会・役職、会員種別、連絡先など、当会の会員名簿・組織図にもとづく情報
  • LINE に関する情報：LINE のユーザーID、表示名、本サービスとのトークやグループで送信されたメッセージ・画像・ファイル、ボタン操作の記録
  • 本サービスの利用に伴う情報：出欠の回答、日程調整・アンケートの回答、専務AIへの質問と回答、回答への評価、操作の記録（監査ログ）
  • Google アカウントを通じて取得する情報：第4条に定める範囲で、当会の公式 Google アカウントの Gmail・Google ドライブ・Google カレンダーの情報

2. 利用目的

取得した情報は、次の目的に限り利用します。

  • 例会・会議・事業の案内、出欠の確認・集計、日程調整、リマインド
  • 会員からの問い合わせへの回答（当会の資料・過去のやり取りにもとづく AI による回答を含みます）
  • 議案・事業計画書・委員会資料の作成、更新および提出状況の管理
  • 対外団体からの連絡の整理・共有、見積依頼など当会の業務に必要なメールの送信
  • 当会の運営に関する集計・分析および本サービスの改善
  • 不正利用の防止、障害対応およびセキュリティの確保

3. AI による処理

本サービスは、質問への回答、資料の案の作成、連絡の要約などに、Google Cloud の生成 AI（Vertex AI / Gemini）を利用します。処理は当会が契約する Google Cloud の環境で行われ、AI の提供者が当会のデータを AI モデルの学習に利用することはありません（Google Cloud の利用規約にもとづきます）。AI の出力は参考情報であり、資料の書き換えやメールの送信など外部に影響する操作は、必ず利用者本人が内容を確認したうえで実行します。

4. Google ユーザーデータの取扱い

本サービスは、当会の公式 Google アカウントの許可を得て、次の範囲で Google の API を利用します。

対象 利用の内容
Gmail（読み取り） 当会あての対外団体からの連絡（所定のラベルが付いたメール）を読み取り、要約して会員に共有します。
Gmail（送信） 見積依頼など当会の業務に必要なメールを、担当者が宛先・本文を確認したうえで送信します。自動で送信することはありません。
Google ドライブ 当会の資料を読み取って会員の質問への回答に利用し、理事メンバーの依頼と確認にもとづいて委員会資料・事業計画書を作成・更新します。
Google カレンダー 当会の例会・会議などの予定を登録・同期します。

本サービスによる Google API から受け取った情報の使用および他のアプリへの転送は、Google API サービスのユーザーデータに関するポリシー（Limited Use の要件を含みます）に準拠します。Google ユーザーデータを広告に利用すること、第三者に販売すること、上記の目的以外に利用することはありません。

5. 第三者への提供と外部サービスの利用

当会は、法令にもとづく場合を除き、本人の同意なく個人情報を第三者に提供しません。本サービスの提供のため、次の外部サービスを利用し、必要な範囲で情報を取り扱います。

  • LINE ヤフー株式会社（LINE Messaging API、LINE ログイン）
  • Google LLC（Google Cloud、Gmail、Google ドライブ、Google カレンダー）

6. 保存場所と保存期間

  • 情報は、主に Google Cloud の東京リージョンに保存します。
  • 会員情報は在籍期間中および退会後の事務に必要な期間、LINE のメッセージ等の記録は最長5年間保存し、その後削除します。
  • 送信を取り消されたメッセージは、本サービスの記録からも内容を削除します。
  • 会員名簿・住所録など特に配慮が必要な資料は、AI の回答の材料として取り込みません。

7. 安全管理

当会は、アクセスできる者の限定（管理画面への認証つきアクセス、役職に応じた操作の制限）、操作の記録、通信の暗号化など、情報の漏えい・滅失・毀損を防ぐための措置を講じます。

8. 開示・訂正・削除等の請求

本人は、当会が保有する自己の情報について、開示、訂正、利用停止、削除を請求できます。LINE との連携の解除を希望する場合も、下記の窓口までご連絡ください。本人であることを確認したうえで、合理的な期間内に対応します。

9. 本ポリシーの変更

当会は、必要に応じて本ポリシーを変更することがあります。重要な変更を行う場合は、本サービスまたは当会のホームページでお知らせします。
