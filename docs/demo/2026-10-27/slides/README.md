# 猪苗代専務AI デモスライド

`index.html` をブラウザで開いて使用します。画像を相対パスで読み込むため、配布するときは `images/` も同じ場所に置いてください。外部CDN・外部フォント・追加ライブラリは使用していません。

## 操作

- 次へ：右矢印、スペース、画面クリック、右下の次へボタン
- 前へ：左矢印、右下の前へボタン
- 最初／最後：Home／End
- 全画面：F または右下の全画面ボタン（対応ブラウザ）
- スマートフォン：左右スワイプ
- 印刷：ブラウザの印刷機能。16:9・1スライド1ページの印刷用CSSを設定しています。ブラウザのヘッダーとフッターはオフにしてください。
- 特定ページ：`index.html#slide-7` のように指定できます。

画面内のLINEメニューや操作ボタンは説明用の図です。実サービスへの接続や送信は行いません。

## 各スライドの要点

| 枚 | 内容 | 要点 |
|---|---|---|
| 1 | 表紙 | LINEでつながる、JCI猪苗代の「もう一人の専務」 |
| 2 | なぜ作ったか | AIが下書きし、人が決める。人にしかできない仕事に時間を使う |
| 3 | 全体像 | 会員はLINEから。AIは資料・カレンダーを参照し、専務・五役は管理画面でも確認 |
| 4 | LINEメニュー | 会員・理事・五役で入口が変わる |
| 5 | 予定と出欠 | 予定の一覧、出欠の回答・変更、自動のお願い・催促 |
| 6 | 日程調整 | LINEで○△×を集め、確定した予定をGoogleカレンダーへ自動登録 |
| 7 | AIに聞く | 過去資料を検索し、資料名・リンク付きで回答。閲覧範囲と個人情報に配慮 |
| 8 | 資料を作る・直す | AIが案を作り、本人が「書き込む」を押したときだけ反映。変更を戻せる |
| 9 | 議案の提出管理 | 台帳から提出して専務に通知。期限超過は担当副理事長へ確認 |
| 10 | 意見箱 | 匿名でも意見を送り、AIが分類・要約して専務へ届ける |
| 11 | 安心のしくみ | 調べて答えるチャット、確認後の書き換え・送信、操作記録、国内保存、学習不使用 |
| 12 | はじめ方 | 名前を選んでLINE連携を申請し、専務の承認後に利用 |

## 生成画像

組み込みの `image_gen`（image_generation）で4点生成し、`images/` に保存しています。

| ファイル | 内容 | 使用スライド |
|---|---|---|
| `images/hero-assistant.png` | スマートフォン、緑の吹き出し、書類 | 1 |
| `images/community-meeting.png` | 架空の地域経済人による会議風景 | 2 |
| `images/documents-draft.png` | 緑のフォルダーとまとまる書類 | 8 |
| `images/security-lock.png` | 透明な緑色の南京錠 | 11 |

最終生成プロンプトは `IMAGE_PROMPTS.md` に記録しています。画像内に日本語や実在ロゴは含めていません。
