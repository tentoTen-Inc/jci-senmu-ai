# 依頼: 「猪苗代専務AI」デモ用スライドの制作

## 目的・場面
- 2026年10月27日(火)、一般社団法人猪苗代青年会議所（JCI猪苗代）の会員向けに、専務理事 遠藤孝行が「猪苗代専務AI」のデモを行う。その冒頭〜途中で投影するスライド。
- 聞き手: JC会員（地域の経営者・若手。ChatGPT を使ったことがある程度。エンジニアではない）。
- 伝えたいこと: 「専務AIで何ができるか」「どう使うか」「安心して使える理由」。
- **デザイン性を最重視**。画像生成（image_generation）を積極的に使い、図解でひと目で分かるスライドにする。

## 成果物（このフォルダ内に作る）
- `slides/index.html` … 16:9 の HTML スライド（1ファイル。←→キー・クリックでページ送り。印刷で1枚1ページ）。外部CDNは使わず、フォントはシステムの日本語フォント（ヒラギノ角ゴ等）で可。
- `slides/images/` … 生成した画像（PNG/JPG/WebP）。HTML からは相対パスで参照。
- 10〜12枚程度。1枚1メッセージ、文字は少なめ・大きめ（会場の後ろからも読める）。

## デザインの方向性
- LINE になじむ、明るく清潔なトーン（白地＋LINEグリーン #06C755 を差し色、濃紺の文字）。親しみやすいが子どもっぽくしない。
- 生成画像の例: スマホに LINE のリッチメニューが表示されたイメージ（ボタン名は下の正式名称）、JC の会議・例会の情景、AI アシスタントが資料を整える抽象イラスト、安全・鍵のモチーフ など。
- **画像の中に日本語の文字を描かせない**（崩れやすい）。文字は HTML 側で重ねる。人物の実名・実在ロゴ・LINE 公式ロゴは使わない。
- 図解（流れ・役割分担・画面の構成）は HTML/CSS/SVG で描いてよい。

## 構成案（この順・内容は事実どおりに）
1. 表紙: 「猪苗代専務AI」— LINE でつながる、JCI猪苗代の“もう一人の専務”／2026.10.27 デモ／専務理事 遠藤孝行
2. なぜ作ったか: 専務の仕事（案内・出欠集め・催促・日程調整・資料の取りまとめ・問い合わせ対応）は量が多い。人にしかできないこと（方針・議論・合意・仲間づくり）に時間を使うため、それ以外を AI に任せる。キーメッセージ「AIが下書きし、人が決める」
3. 全体像（図）: 会員は LINE だけで使える／AI がドライブの資料・LINE の資料・カレンダーをもとに動く／専務・五役は管理画面でも確認できる
4. LINE のメニュー（図・画像）: 立場ごとにメニューが変わる
   - 会員: 予定と出欠／日程調整／AIに聞く／意見箱
   - 理事（委員長など）: ＋資料を作る・直す／委員会の議案
   - 五役: 「みんな」と「運営」のタブ。運営＝予定を登録・変更／出欠の状況／日程調整を作る／承認待ち／管理画面を開く
5. できること①予定と出欠: これからの予定を一覧→その場で出欠を回答・変更。締切前に自動で出欠のお願い・催促。五役は未回答者を確認して催促できる
6. できること②日程調整: 候補日をLINE上で○△×回答。五役・理事会・全員・委員会ごとに使える。催促・確定→Googleカレンダーへ自動登録
7. できること③AIに聞く: 「去年の〇〇はどうやった？」「この様式はどこ？」に、ドライブの過去資料や LINE の資料を調べて答える。出典（資料名・リンク）付き。五役向けの資料は五役にだけ。名簿・住所録などの個人情報は使わない。分からないときは「分からない」と答える
8. できること④資料を作る・直す（理事・五役）: 委員会サマリーや事業計画書を選ぶ→「〇〇な例会にしたいので背景と目的を書いて」と会話→AI が案を作る→本人が［書き込む］を押したときだけ Google ドキュメントに反映→［さっきの変更を戻す］も可。新しい事業計画書をテンプレートから作成（基本情報も自動記入）
9. できること⑤議案の提出管理: 委員会の議案（サマリー・事業計画書）を台帳で一覧。［提出する］ボタンで提出→専務に通知。締切を過ぎたら担当副理事長に知らせ、提出予定日を回答してもらう
10. できること⑥意見箱: 不具合・ほしい機能・使いにくい点を LINE から送れる（匿名も可）。AI が分類・要約して専務に届く。みんなの声で育てる
11. 安心して使えるしくみ: ふだんのチャットは「調べて答える」だけ（勝手に書き換えない）／書き換え・送信はボタン＋確認のあとだけ／操作は記録に残る／データは国内（Google Cloud 東京）に保存・AI の学習には使われない／個人情報は検索に使わない
12. はじめ方・まとめ: LINE 連携（リンクから自分の名前を選んで申請→専務が承認）→メニューから使う。「わからないことは、まず専務AIに」／「意見箱で一緒に育てましょう」

## 注意
- 上に書いていない機能を足さない。数字（件数・割合・効果）を作らない。
- 会員の実名は「専務理事 遠藤孝行」以外は出さない。
