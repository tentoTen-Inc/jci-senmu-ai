## B. マニュアル動画（約 12 分・章ごとに目次つき）

### 0. はじめに（0:00〜0:40）
**画面**: タイトル →「この動画でわかること」の目次
**ナレーション**:
この動画では、青年会議所の専務の仕事を手伝う「専務AI」の使い方を、はじめから順番に説明します。前半は、会員が LINE で使う機能。後半は、専務と五役が使う管理画面と、導入のしかたです。

### 1. 全体のしくみ（0:40〜1:40）
**画面**: 図（会員の LINE ↔ 専務AI ↔ Google ドライブ・カレンダー・LINE の資料／専務・五役 ↔ 管理画面）
**ナレーション**:
専務AI は、LOM の LINE 公式アカウントとして動きます。会員はいつもの LINE から使うだけで、新しいアプリを入れる必要はありません。
専務AI は、Google ドライブの資料、LINE のグループで共有された資料、Google カレンダーの予定をもとに動きます。専務と五役は、パソコンやスマホのブラウザで開く管理画面でも、状況を確認したり、操作したりできます。
大切にしているのは「AI が下書きし、人が決める」ことです。案内や催促、集計のような繰り返しの仕事は AI に任せて、方針や議論、仲間づくりのように、人にしかできないことに時間を使えるようにします。

### 2. LINE 連携（1:40〜2:40）
**画面**: グループに届く「LINE 連携のお願い」→［LINE 連携をする］→ 名前を選ぶ → 申請 → 管理画面の「承認待ち」→ 承認 → 個別トークに完了の知らせ
**ナレーション**:
はじめに、会員の LINE と名簿を結びつけます。専務がグループに「LINE 連携のお願い」を送ると、会員はボタンを押して、自分の名前を選ぶだけで申請できます。
申請は専務のところに届き、専務が承認すると連携が完了します。本人が選んだ名前を専務が確かめるので、なりすましを防げます。連携が終わると、立場に合ったメニューが表示されるようになります。

### 3. 立場ごとのメニュー（2:40〜3:30）
**画面**: 会員・理事・五役のリッチメニューを並べて表示 → 五役の［みんな］［運営］タブの切り替え
**ナレーション**:
メニューは立場によって変わります。会員のメニューは、［予定と出欠］［日程調整］［AIに聞く］［意見箱］の四つ。
委員長などの理事には、［資料を作る・直す］と［委員会の議案］が加わります。
五役のメニューには［みんな］と［運営］の二つのタブがあり、［運営］では、予定の登録・変更、出欠の状況、日程調整を作る、承認待ち、管理画面を開く、が使えます。

### 4. 予定と出欠（3:30〜4:40）
**画面**: ［予定と出欠］→ 予定の一覧 → 出席を選ぶ → 変更する → 締切前のお願いのメッセージ →（五役）出欠の状況 → 未回答者に催促
**ナレーション**:
［予定と出欠］を開くと、自分が対象のこれからの予定が並びます。出席か欠席を選ぶだけで回答でき、あとから変えることもできます。
締切が近づくと、まだ答えていない人にだけ、自動でお願いのメッセージが届きます。夜九時から朝八時までは送らないので、夜中に通知が鳴ることはありません。
五役は［出欠の状況］から、予定ごとの回答と未回答の人を確かめて、その場で催促を送れます。

### 5. 日程調整（4:40〜5:50）
**画面**: （五役）［日程調整を作る］→ 対象者・候補日を入れる → グループに案内が届く → 会員が○△×で回答 → 回答の一覧 → 日にちを決める → 予定と出欠・カレンダーに入る
**ナレーション**:
会議の日程は、LINE で調整できます。五役は［日程調整を作る］から、対象者と候補日を入れるだけ。五役会、理事会、委員会、会員全員と、対象者に合わせたグループに案内が届きます。
会員は候補日ごとに○、△、×で答えます。ほかの人の回答も見られるので、決めやすくなります。
日にちを決めると、その予定がそのまま［予定と出欠］に入り、○と答えた人は出席、×の人は欠席として写されます。Google カレンダーにも自動で登録されます。

### 6. AI に聞く（5:50〜7:00）
**画面**: ［AIに聞く］→ 質問を入力 → 出典つきの回答 → 出典のリンクを開く → 👍👎 で評価 → グループでメンションして質問
**ナレーション**:
わからないことは［AIに聞く］から質問できます。「去年の新年例会はどうやった？」「この様式はどこにある？」といった質問に、ドライブの過去の資料や、LINE で共有された資料を調べて答えます。答えには出典がつくので、元の資料をすぐに開けます。
五役向けの資料は五役にだけ使い、名簿や住所録のような個人情報は、そもそも検索の対象にしません。資料に書かれていないことは、推測で答えずに「わからない」と答えます。
グループで専務AI をメンションして質問することもできます。そのときは、そのグループのやり取りと、全員向けの資料だけを使って答えます。

### 7. 資料を作る・直す（7:00〜8:10）
**画面**: （理事）［資料を作る・直す］→ 事業計画書を選ぶ →「○○な例会にしたいので、背景と目的を書いて」→ AI の案 →［書き込む］→ Google ドキュメントに反映 →［さっきの変更を戻す］
**ナレーション**:
委員長などの理事は、［資料を作る・直す］から、委員会サマリーや事業計画書を AI と一緒に作れます。資料を選んで、「こんな例会にしたいので、背景と目的を書いて」と話しかけると、AI が案を作ります。
案は、本人が［書き込む］を押したときだけ、Google ドキュメントに反映されます。気に入らなければ［さっきの変更を戻す］で元に戻せます。
新しい議案書も LINE から作れます。［＋新しい事業計画書］を選び、委員会と、年間スケジュールの例会や事業をボタンで選ぶだけで、テンプレートから事業計画書を作ります。委員会名や委員長などの基本情報も自動で記入されるので、そのまま AI と続きを書き進められます。

### 8. 委員会の議案（作成・チェック・段階の管理）
**画面**: ［委員会の議案］→ 議案の一覧 →［提出する］→ 専務に通知 → 締切後、担当の副理事長への知らせ → 提出予定日を選ぶ → 管理画面で形式チェック・AI の確認 → 議案の台帳（段階）
**ナレーション**:
委員会の議案は、台帳で会議ごとに管理します。［委員会の議案］から自分の委員会の議案を確かめ、準備ができたら［提出する］を押すだけ。専務に知らせが届きます。
締切を過ぎても提出されていない議案は、担当の副理事長に知らせが届き、提出予定日を答えてもらいます。
提出された議案は、管理画面でチェックできます。体裁のチェックでは、必須の項目が抜けていないか、英数字の全角と半角が混ざっていないかを調べます。さらに AI が内容を読み、要約と気になる点を出します。細かな確認は AI に任せて、専務と五役は、議論すべき中身に集中できます。最終的な判断は、人が行います。
議案は、エントリー、資料提出、五役会、理事会上程、審議結果、事業実施、報告、検証の段階で管理します。どの議案がいまどこにあるかが一目でわかるので、上程漏れを防げます。

### 9. 意見箱（9:00〜9:30）
**画面**: ［意見箱］→ 種類を選んで送る（匿名も可）→ 管理画面の意見箱（分類・要約）
**ナレーション**:
［意見箱］からは、不具合や、ほしい機能、使いにくいところを送れます。名前を出さずに送ることもできます。届いた意見は AI が分類して要約し、専務に届きます。みんなの声で、専務AI を育てていきます。

### 10. 管理画面（9:30〜11:00）
**画面**: ホーム → 予定・出欠 → 日程調整 → 会員・LINE連携 → 議案 → 連絡・アンケート → 意見箱 → LINE のやり取り → AI の回答 → 送信の記録 → 設定（送信の一時停止）
**ナレーション**:
専務と五役は、管理画面でもすべてを確認できます。管理画面には、許可した Google アカウントだけがログインできます。
ホームには、今やることがまとまっています。予定・出欠では、予定ごとの回答と集計を、日程調整では回答の一覧と、日にちの決定を。会員・LINE連携では、連携の状況と承認待ちを確認できます。
議案、外部からの連絡とアンケート、意見箱、LINE のグループのやり取り、AI の回答と評価、送信の記録も、ここで見られます。
設定では、送らない時間帯や送信数の上限を決められます。万が一のときは、［送信の一時停止］で、LINE への自動送信をすぐに止められます。

### 11. 安心して使うために（11:00〜11:40）
**画面**: 鍵のイラスト＋箇条
**ナレーション**:
ふだんのチャットは、調べて答えるだけで、勝手にデータを書き換えることはありません。書き換えや送信は、ボタンを押して、確認したあとだけ。操作はすべて記録に残ります。
データは、自分の LOM の Google Cloud の東京リージョンに保存され、AI の学習に使われることはありません。

### 12. 導入のしかた（11:40〜12:30）
**画面**: GitHub のリポジトリ → README → セットアップ手順の目次（Google Cloud・LINE・デプロイ・初期データ）
**ナレーション**:
専務AI は、オープンソースとして無料で公開しています。自分の LOM の Google Cloud と LINE 公式アカウントがあれば、誰でも導入できます。
手順は GitHub のセットアップ手順にまとめました。Google Cloud の準備、LINE の設定、デプロイ、会員名簿の取り込みの順に進めます。
地方で頑張る、全ての専務へ。専務AI が、少しでも力になれたらうれしいです。
